## Требования

Установленный Node.js: https://nodejs.org/

## Установка и запуск

1. Склонируйте репозиторий:

   ```bash
   git clone https://github.com/BazhenovDev/bookCalculator.git
   ```

2. Перейдите в папку проекта:

   ```bash
   cd bookCalculator
   ```

3. Запустите программу:

   ```bash
   node app.js
   ```

4. Введите количество книг для обработки. После расчёта введите `1`, чтобы повторить расчёт, или `0`, чтобы завершить программу.
